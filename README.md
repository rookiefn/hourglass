# Hourglass

到某一天的倒计时。纯静态网页应用（PWA），可以添加到手机主屏幕当 App 用。

不登录、不联网、没有服务器：**数据只存在打开它的那台设备的浏览器里**。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 唯一页面：列表 / 新建编辑 / 设置 / 分享视图 |
| `styles.css` | 深色极简 + 浅色两套，跟随系统自动切 |
| `app.js` | 列表渲染、长按拖拽排序、分享、备份导入导出 |
| `store.js` | 本机存储读写 + 分享链接编解码，**不含任何网络请求** |
| `sw.js` | 离线缓存（联网优先、断网兜底） |
| `manifest.webmanifest` | 添加到主屏幕所需的配置 |
| `icons/` | 沙漏图标：`icon.svg`（矢量）+ `icon-1024.png`（iOS 用） |

零依赖、零构建：改完直接刷新即可，没有编译步骤。

## 功能

- 多个倒计时，列表展示，**只显示天数**（不跳秒）
- 到期当天的自动置顶并高亮，已过期的变灰沉到最底部
- **长按卡片 0.38 秒**可上下拖动排序（只在「今天 / 未来 / 已过期」各自组内拖）
- 拖着不顺手时，**点开某一条倒计时，面板里还有「上移 / 下移」**可以挪（不依赖手势，必定可用）
- 每条可写一句备注、选 8 种颜色之一
- 点开某一条 → 「分享给朋友」：**倒计时数据编码在链接里**，朋友点开就能看，也能一键复制到自己的列表
- 设置里可导出 / 导入备份（换手机不丢），可清空全部数据

## 桌面上的倒计时（不属于这个应用）

需求："像时钟、天气那样，在手机桌面上显示某个日子的名称和倒计时。"

**结论：用手机系统自带的功能实现，本项目不掺和。** 原因是桌面小组件属于系统级能力，**网页应用（PWA）在 iOS 和 Android 上都拿不到这个接口**——这不是实现得好不好的问题，是平台不开放。另外网页的数据存在浏览器沙箱里，别的 App 读不到，所以"网页里改了、桌面跟着变"在没有服务器的前提下不可能做到。

当前方案（荣耀 MagicOS 自带日历，零安装，2026-09-18 实测可用）：

1. 打开「日历」→ 右下角「+」新建日程
2. 标题填日子名称，开始时间选到目标日
3. 点「添加更多项」→ 打开「**桌面倒数日卡片**」开关（提醒建议关掉）
4. 保存后回到桌面 → **双指捏合** → 「桌面卡片」→ 选「日历」→ 左滑找到「倒数日」→ 添加到桌面
5. 点桌面上的卡片可切换显示哪个日程、换卡片样式

官方说明：https://www.honor.com/cn/support/content/zh-cn15836205/ （写的是 MagicOS 7.0，更高版本菜单位置可能略有出入）

**如果哪天要跟网页联动**：那必须加云端（网页把数据存到服务器、小组件去读），工程量比现在整个应用还大，而且又回到要服务器、要花钱。

## 换托管 / 首次上线

本项目已经挂在 GitHub Pages 上（见上）。要换到别处，或从零再来一遍：

**GitHub Pages**
1. 在 GitHub 建仓库，建议设成**公开**（免费账号的私有仓库一般不能发布 Pages）。
2. 把 7 个应用文件（含 `icons/`）传到仓库**根目录**，`index.html` 必须在根上。
3. 仓库 `Settings` → `Pages` → Source 选 `Deploy from a branch` → `main` / `/ (root)` → Save。
4. 等 1~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

**国内访问更快的选择**（等要用时再折腾）
- 腾讯 EdgeOne Pages：免费、国内节点。**实测受阻**（2026-09-18）：部署时报 `FailedOperation: Zone is not active`，属于账号未开通 EdgeOne 服务，需要先去控制台开通/实名一次，之后一键部署即可。
- 腾讯云开发静态网站托管：默认域名国内可访问；但注意**不要**复用 `批查查` 那个已有环境，另开一个，且可能涉及套餐费用。

所有资源都写成相对路径，所以挂在子路径下（如 `/hourglass/`）不会坏；换到别的静态托管同样只需传文件，代码一行不用改。
