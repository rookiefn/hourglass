# Hourglass

到某一天的倒计时。纯静态网页应用（PWA），可以添加到手机主屏幕当 App 用。

不登录、不联网、没有服务器：**数据只存在打开它的那台设备的浏览器里**。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 唯一页面：列表 / 新建编辑 / 设置 / 分享视图 |
| `styles.css` | 深色极简 + 浅色两套，跟随系统自动切 |
| `app.js` | 列表渲染、长按拖拽排序、分享、备份导入导出 |
| `store.js` | 本机存储读写 + 分享链接编解码，**不含任何网络请求** |
| `sw.js` | 离线缓存（联网优先、断网兜底） |
| `manifest.webmanifest` | 添加到主屏幕所需的配置 |
| `icons/` | 沙漏图标：`icon.svg`（矢量）+ `icon-1024.png`（iOS 用） |

零依赖、零构建：改完直接刷新即可，没有编译步骤。

## 功能

- 多个倒计时，列表展示，**只显示天数**（不跳秒）
- 到期当天的自动置顶并高亮，已过期的变灰沉到最底部
- **长按卡片 0.38 秒**可上下拖动排序（只在「今天 / 未来 / 已过期」各自组内拖）
- 拖着不顺手时，**点开某一条倒计时，面板里还有「上移 / 下移」**可以挪（不依赖手势，必定可用）
- 每条可写一句备注、选 8 种颜色之一
- 点开某一条 → 「分享给朋友」：**倒计时数据编码在链接里**，朋友点开就能看，也能一键复制到自己的列表
- 设置里可导出 / 导入备份（换手机不丢），可清空全部数据

## 换托管 / 首次上线（GitHub Pages）

1. 在 GitHub 建仓库，建议设成**公开**（免费账号的私有仓库一般不能发布 Pages）。
2. 把本目录里的 7 样东西传到仓库**根目录**，`index.html` 必须在根上。
3. 仓库 `Settings` → `Pages` → Source 选 `Deploy from a branch` → `main` / `/ (root)` → Save。
4. 等 1~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

所有资源都写成相对路径，所以挂在子路径下（如 `/hourglass/`）不会坏；换到别的静态托管同样只需传文件，代码一行不用改。

## 更新日志

**2026-09-18** 修复手机上拖不动排序
- 修复：手机上长按能进入拖拽（有震动），但手指一移动卡片就弹回原位。原因是触摸拖拽交给 pointer 事件时，浏览器会把这段手势判成「滚动列表」并收走手势。改为触摸走 touch 事件，且把非 passive 的 touchmove 监听常驻注册（详见 `CONTEXT.md` 第四节第 8 条）
- 新增：编辑面板里的「上移 / 下移」，作为不依赖手势的排序兜底
- 调整：拖拽开始时提示文案、设置里的排序说明同步更新
- 注意：本次重新部署换了新网址，新网址是一份全新的浏览器存储，旧网址上的数据不会跟过来
